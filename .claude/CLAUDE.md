# CLAUDE.md — «Симфония мебели»

Инструкции для Claude Code по этому проекту.

## Что это
Сайт мебельной компании «Симфония мебели» (ребрендинг THE WOOD): кухни и корпусная мебель на
заказ. Next.js 14 (App Router, TS) + Tailwind + Prisma/Postgres + NextAuth + ЮKassa + Claude API.

## Стек и конвенции
- **Next.js App Router**, все компоненты по умолчанию серверные; `"use client"` — только там, где
  нужны состояние/эффекты/браузерные API.
- **TypeScript strict**. Псевдоним импорта `@/*` → `src/*`.
- **Tailwind по дизайн-токенам** из `design/tokens.json` и `tailwind.config.ts`. Не хардкодить
  цвета в разметке — использовать палитру `wood-*`, `graphite-*`, `cream-*`.
- **Prisma** — единственный источник правды по данным каталога. Изменения модели: правим
  `prisma/schema.prisma` → `npm run prisma:migrate`.
- Формы валидируются через **zod** (`src/lib/validators.ts`).
- Секреты только в `.env` (см. `.env.example`), никогда в клиентском коде/коммитах.

## Ключевые модули
- `src/lib/db.ts` — Prisma singleton.
- `src/lib/ai.ts` — Claude API (модель Haiku), системный промпт консультанта.
- `src/lib/yookassa.ts` — REST-обёртка ЮKassa (создание/получение платежа).
- `src/lib/video.ts` — задел под виртуализацию квартиры по планировке (Runway/аналог).
- `src/lib/cart.ts` — клиентская корзина (zustand + localStorage).
- `src/lib/catalog.ts` — выборки каталога с фильтрами.
- `src/lib/auth.ts` — NextAuth (credentials) для `/admin`.

## Дизайн-принципы (заказчик)
Спокойная, статусная эстетика; приглушённая палитра (дерево/графит/тёплый белый); крупная воздушная
типографика; много пространства; крупные фото как основной визуальный якорь; единый стиль карточки
товара во всех категориях.

## Каталог
Только два раздела: **Кухни** (`kuhni`) и **Корпусная мебель** (`korpusnaya-mebel`). Столы/Стулья
убраны из меню; модель `Category` поддерживает дерево (`parentId`) — при необходимости вернуть
подкатегориями.

## Проверки перед коммитом
```
npm run typecheck && npm run lint && npm run build
```

## Чего не делать
- Не пушить и не деплоить автоматически — это делает пользователь вручную после ревью.
- Не коммитить `.env` и любые реальные ключи.
